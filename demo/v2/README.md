# Submission demo v2

The current 2:59 narrated demo is **Offload-demo-v2.mp4**. It presents the attention cost that motivated Offload, live Sell and Find flows, each Meta model's role, the API-cost estimate for the recorded run, and the ambition to build directly into Facebook Marketplace.

The prototype is not integrated with Marketplace. The sample photograph is synthetic, counterpart buyers are simulated, and Find receives manually entered offers. Accelerated waits and typing are labeled. The USD0.0971 application estimate excludes hosting, development and video narration; it is not a provider invoice or a cost per real sale. Rime Coda/Lawton supplies video narration only. Optional Muse Voice Transcribe is not demonstrated.

The older files in the parent demo folder are retained as historical evidence, not the submission video. See VERIFICATION.json for this export's hash and measured properties.
